# 宽基指数与自选清单估值查看器

两个页签：

- **低点信号** —— 标普500 / 纳斯达克100 / VOO / QQQ / AAPL 的价格走势与局部低点信号回测
- **估值面板** —— 24 个标的（TradingView 自选清单 20 只 + QQQ / VOO / SMH / AIS / DRAM）的
  PE TTM、Forward PE、PB 历史走势与估值百分位

数据来源：macrotrends（每股收益与每股净资产，约 20 年季度锚点）、stockanalysis（前瞻市盈率、
PEG、市值）、Siblis Research（纳斯达克100 指数估值）、multpl 与 FactSet（标普500 指数估值）、
Yahoo Finance（日频价格）。

日频市盈率的分子是真实当日收盘价，分母是季度财报锚点插值出来的每股收益。
百分位分两套口径，页面上每个数字都标了窗口。

**本页只呈现公开市场数据及其历史分布位置，不构成投资建议。**
